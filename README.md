# Pause for Paws

“Pause for Paws” is an interactive hybrid animation about rabies awareness that follows the protagonist, Kai, through different scenarios involving dogs. At certain points in the story, you’ll make choices that influence how the situations unfold and lead to different outcomes. Through these interactive scenarios, you’ll learn about rabies, how to respond to dog encounters, and the importance of proper wound care and seeking immediate medical attention.
